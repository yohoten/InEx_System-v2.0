### Q2: 如何恢复默认凭据？

**A**: 删除配置文件中的 `login` 节：

1. 关闭应用
2. 用文本编辑器打开 `config.json`
3. 找到并删除以下内容：
   ```json
   "login": {
     "account_encrypted": "...",
     "password_hash": "..."
   },
   ```
4. 保存文件并重启应用
5. 系统会自动重新初始化默认凭据

### Q3: secret.key 文件丢失怎么办？

**A**: 直接删除 `secret.key` 文件，重启应用后会自动生成新密钥。

⚠️ **注意**：删除密钥后将无法解密之前保存的凭据，需要重新设置密码。

### Q4: 可以在多台电脑上使用相同凭据吗？

**A**: 不可以。每台电脑的 `secret.key` 不同，凭据加密是机器相关的。

如需同步凭据，需要：
1. 复制 `secret.key` 文件到另一台电脑
2. 复制 `config.json` 中的 `login` 配置节

## 🛡️ 安全最佳实践

### ✅ 推荐做法

1. **立即修改默认密码**：首次登录后马上修改
2. **使用强密码**：包含大小写字母、数字、特殊字符
3. **定期更换密码**：建议每90天更换一次
4. **保护 secret.key**：不要分享给他人
5. **备份配置文件**：定期备份 `config.json` 和 `secret.key`

### ❌ 避免做法

1. ❌ 不要将 `secret.key` 上传到公开代码仓库
2. ❌ 不要使用简单密码（如 123456、password）
3. ❌ 不要在多个系统间共享相同的 `secret.key`
4. ❌ 不要忽略"首次运行提示"
