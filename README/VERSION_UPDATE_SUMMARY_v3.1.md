## 🔧 核心变更

### 1. 代码质量修复

#### 修复裸except语句 (settings_page_backup_old.py)

**问题**: 2处使用裸`except:`语句，可能捕获系统信号并掩盖严重错误

**修复内容**:
- Line 1397: Sybase数据库名称查询异常处理
- Line 1460: Sybase版本信息查询异常处理

**改进效果**:
```python
# 修复前 - 静默失败，无法追踪问题
except:
    pass

# 修复后 - 详细日志，便于调试
except Exception as e:
    self.log_text.append(f"[WARN] 查询数据库名称失败: {str(e)}")
```

**影响范围**: 
- 提升错误追踪能力
- 符合Python最佳实践（PEP 8）
- 不影响功能逻辑
