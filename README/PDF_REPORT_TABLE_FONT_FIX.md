# PDF报告表格中文显示修复记录

## 问题描述
在生成的PDF财务分析报告(`收支分析报告.pdf`)中,表格内的中文内容显示为**黑色小方块**,而非正常的汉字。

## 根本原因
ReportLab的`Table`组件**不会自动继承全局字体设置**。虽然代码中已注册了中文字体(STSong-Light或SimSun),但在创建表格时,仅在`TableStyle`中为**表头行**设置了字体,而**数据行**仍然使用默认的Helvetica字体,导致中文无法正确渲染。

### 错误示例
```python
# ❌ 仅设置表头字体 - 数据行仍用Helvetica
TableStyle([
    ('FONTNAME', (0, 0), (-1, 0), 'ChineseFont'),  # 只有第0行(表头)
    ...
])
```

### 正确做法
```python
# ✅ 设置全表字体 - 所有单元格都使用中文字体
TableStyle([
    ('FONTNAME', (0, 0), (-1, -1), 'ChineseFont'),  # 从(0,0)到最后一行最后一列
    ...
])
```

## 技术要点

### ReportLab Table字体设置规范
- **坐标系统**:`(列, 行)`,从`(0, 0)`开始
- **范围表示**:`(start_col, start_row), (end_col, end_row)`
- **全表选择**:`(0, 0), (-1, -1)` 表示从左上角到右下角的所有单元格
- **负数含义**:`-1`表示最后一列/最后一行

### 为什么需要显式设置?
ReportLab的设计哲学是**最小化隐式行为**:
1. `Paragraph`组件会自动使用注册的默认字体
2. `Table`组件需要显式指定每个单元格的样式
3. 这是为了支持表格内混合使用多种字体(如中英文混排)
