## 📊 代码架构

### 模块化设计

采用 **Mixin模式** 实现功能分离：

```
ui/pages/
├── settings_page.py          # 主页面类（继承SettingsFeaturesMixin）
└── settings_features.py      # 功能模块（SettingsFeaturesMixin类）
```

**优势**：
- ✅ 保持主页面文件整洁
- ✅ 功能模块可独立测试
- ✅ 便于后续扩展和维护
- ✅ 符合单一职责原则

### 类继承结构

```python
class SettingsFeaturesMixin:
    """系统设置功能混入类"""
    def load_real_logs(self): ...
    def export_settings(self): ...
    def import_settings(self): ...
    def view_backup_history(self): ...
    def delete_backup_file(self, ...): ...
    def refresh_backup_history(self, ...): ...

class SettingsPage(SettingsFeaturesMixin, QWidget):
    """系统设置页面"""
    # 继承所有功能方法
```

## 📝 使用说明

### 查看真实日志
1. 进入"系统设置"页面
2. 找到"📝 日志配置"区域
3. 点击"📄 加载真实日志"按钮
4. 日志文本框将显示最近100条日志记录

### 查看备份历史
1. 进入"系统设置"页面
2. 找到"💾 自动备份"区域
3. 点击"📋 备份历史"按钮
4. 在弹出的对话框中查看所有备份
5. 可点击"🗑️ 删除"按钮删除不需要的备份

### 导出设置
1. 进入"系统设置"页面
2. 配置好所有参数
3. 点击底部的"📤 导出设置"按钮
4. 选择保存位置和文件名
5. 设置将保存为JSON文件

### 导入设置
1. 进入"系统设置"页面
2. 点击底部的"📥 导入设置"按钮
3. 选择之前导出的JSON文件
4. 确认导入（会显示导出时间和版本）
5. 重启应用使设置生效

## 📌 注意事项

### 1. 日志文件
- 日志文件位于 `logs/` 目录
- 文件名格式：`InEx_system_YYYYMMDD.log`
- 每天自动生成新日志文件

### 2. 备份文件
- 默认备份目录：`data/backups`
- 可在系统设置中修改备份路径
- 备份文件格式：`.db` 或 `.sqlite`

### 3. 配置文件
- 导出格式：JSON
- 包含敏感信息：数据库路径等
- 建议妥善保管导出的配置文件

### 4. 导入限制
- 仅支持本系统导出的JSON格式
- 导入后需要重启应用
- 会覆盖当前所有设置
