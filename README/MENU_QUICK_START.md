## 📋 新增菜单一览

### 1️⃣ 视图菜单 (V) - 个性化你的界面

#### 🎨 切换主题
```
操作: 视图 → 主题 → 深色主题
效果: 界面立即变为深色护眼模式
快捷键: 无（建议使用鼠标）
```

#### 🔤 调整字体
```
操作: 视图 → 字体大小 → 大
效果: 所有文字变大，重启后生效
适用: 视力不佳或高分辨率屏幕
```

#### 📋 折叠侧边栏
```
操作: 视图 → 切换侧边栏
快捷键: Ctrl+Shift+L
效果: 侧边栏从280px缩小到60px（图标模式）
再次执行可展开
```

#### 🔄 刷新页面
```
操作: 视图 → 刷新当前页
快捷键: F5
效果: 重新加载当前页面的数据
适用: 数据更新后手动刷新
```

#### ⛶ 全屏模式
```
操作: 视图 → 全屏模式
快捷键: F11
效果: 隐藏标题栏和边框，专注内容
再次按F11退出
```

### 4️⃣ 文件菜单 (F) - 数据安全

#### 💾 备份数据（重要！）
```
操作: 文件 → 备份数据
快捷键: Ctrl+B
步骤:
1. 点击菜单项
2. 选择保存位置
3. 输入文件名（建议保留默认时间戳）
4. 点击保存
效果: 创建数据库完整备份
频率: 建议每周至少备份一次
```

#### ♻️ 恢复数据
```
警告: 此操作会覆盖当前所有数据！
操作: 文件 → 恢复数据
快捷键: Ctrl+Shift+R
步骤:
1. 系统弹出确认对话框
2. 点击"是"继续
3. 选择备份文件
4. 等待恢复完成
5. 重启应用
注意: 恢复前建议先备份当前数据
```

## ⚠️ 注意事项

### 数据安全
1. **定期备份**: 至少每周备份一次
2. **多重备份**: 本地+外部硬盘+云盘
3. **恢复谨慎**: 恢复前务必确认备份文件正确

### 性能优化
1. **定期优化**: 每月执行一次"优化数据库"
2. **清理冗余**: 每季度清理一次冗余数据
3. **关闭全屏**: 长时间不用时退出全屏模式

### 快捷键冲突
1. 某些快捷键可能与系统或其他应用冲突
2. 如遇冲突，可在系统设置中自定义（计划中）
3. 优先使用鼠标操作作为备选

## 🆘 遇到问题？

### 问题1: 菜单项灰色不可用
```
原因: 功能尚未实现或需要前置条件
解决: 
- 检查是否已配置API Key（AI功能）
- 检查数据库是否连接
- 查看详细文档了解具体要求
```

### 问题2: 快捷键无效
```
原因: 
- 焦点不在主窗口
- 与其他应用冲突
解决:
- 确保主窗口处于激活状态
- 使用鼠标操作替代
```

### 问题3: 主题切换后显示异常
```
原因: 深色主题仍在开发中
解决:
- 切换回浅色主题
- 等待后续版本完善
```

### 问题4: 备份文件太大
```
原因: 数据库中包含大量历史数据
解决:
- 编辑 → 数据库 → 清理冗余数据
- 编辑 → 数据库 → 优化数据库
- 考虑归档旧数据
```
