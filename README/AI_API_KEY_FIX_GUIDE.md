# AI API Key 配置问题修复指南

## ❓ 问题描述

您已经配置了DeepSeek API Key，但点击"获取AI建议"时仍然提示：
```
请先配置 DeepSeek API Key
配置后将自动保存，无需重复输入
```

## 🔍 问题原因

经过排查，发现以下问题：

### 1. **保存逻辑缺失** (已修复)
- **原问题**: `save_all_settings()` 方法没有调用API配置保存
- **影响**: 即使点击"保存所有设置"，API Key也不会被保存到配置文件
- **状态**: ✅ 已修复

### 2. **密钥文件不一致**
- **可能原因**: `secret.key` 文件在不同时间被重新生成
- **影响**: 加密和解密使用不同的密钥，导致读取失败
- **状态**: ⚠️ 需要验证

### 3. **配置文件未写入**
- **可能原因**: 权限问题或路径错误
- **影响**: config.json中没有`ai`配置节
- **状态**: ⚠️ 需要验证

## 🔧 技术细节

### 配置文件结构

**config.json** (保存后应包含):
```json
{
  "ai": {
    "api_key_encrypted": "gAAAAABl...",  // 加密后的API Key
    "model": "deepseek-chat",
    "temperature": 0.7,
    "max_tokens": 1000
  }
}
```

### 密钥文件

**secret.key**:
- 格式: Fernet密钥（44字节Base64编码）
- 作用: 用于加密/解密API Key
- 注意: **不要手动修改或删除**

### 加密流程

```
用户输入 API Key
    ↓
Fernet.encrypt(api_key)  # 使用 secret.key 加密
    ↓
保存到 config.json['ai']['api_key_encrypted']
    ↓
读取时 Fernet.decrypt(encrypted_key)  # 使用相同的 secret.key 解密
    ↓
返回明文 API Key
```

## 💡 常见问题

### Q1: 为什么每次重启都要重新输入API Key？
**A**: 因为之前版本存在bug，`save_all_settings()` 没有保存API配置。现已修复，只需重新配置一次即可。

### Q2: API Key保存在哪里？安全吗？
**A**: 
- 位置: `config.json` 中的 `ai.api_key_encrypted` 字段
- 安全性: 使用Fernet对称加密，密钥存储在 `secret.key` 文件中
- 建议: 不要将这两个文件上传到公开仓库

### Q3: 可以手动编辑config.json吗？
**A**: **不建议**。加密的API Key无法手动编辑，必须通过程序保存。

### Q4: 如何更换API Key？
**A**: 
1. 在"系统设置"中输入新的API Key
2. 点击"测试"按钮
3. 新Key会覆盖旧Key

### Q5: 诊断工具显示"解密失败"怎么办？
**A**: 
1. 删除 `secret.key` 文件
2. 重新配置API Key（会生成新的密钥）
3. 或者执行"方案3：重置配置"
