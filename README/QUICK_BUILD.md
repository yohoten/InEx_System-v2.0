# 🚀 快速打包指南（文件夹模式 + UPX 压缩）

## ✨ 什么是文件夹模式 + UPX？

**三重优化策略**:
1. **文件夹模式**: 启动速度快 3-5 倍，运行时占用更少空间
2. **智能排除**: 自动移除不必要的模块，减小基础体积
3. **UPX 压缩**: 进一步压缩可执行文件，减小 30-50% 体积

**最终效果**: 从 200-250 MB 降至 **45-70 MB**（ZIP 压缩后），总体积减少 **70-75%**！🎯

---

## 🗜️ UPX 压缩说明

### 默认配置

项目已预配置 UPX 路径：`H:\UPX\upx.exe`

如果你的 UPX 在其他位置，编辑 `build.py` 第 22 行：

```python
UPX_PATH = r"你的UPX路径\upx.exe"
```

### 如果没有 UPX？

**完全不影响！** 脚本会自动检测：
- ✅ 有 UPX → 启用压缩（体积更小）
- ⚠️ 无 UPX → 跳过压缩（正常打包）

### 下载 UPX

1. 访问: https://github.com/upx/upx/releases
2. 下载: `upx-xxx-win64.zip`
3. 解压到任意目录（如 `H:\UPX\`）
