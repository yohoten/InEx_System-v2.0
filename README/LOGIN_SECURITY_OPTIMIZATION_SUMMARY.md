## 🎯 解决的核心问题

### 原始问题（来自代码审查报告）

> **文件**: `ui/login_dialog.py:308-336`
> 
> ```python
> # 硬编码验证
> if account == "2501033401" and password == "admin0457":
> ```
> 
> **问题**: 管理员账号密码硬编码在源代码中，任何能访问源码的人都能获取凭据。

### 解决方案

1. ✅ **移除硬编码**：凭据从配置文件加密读取
2. ✅ **密码哈希**：使用bcrypt，即使配置泄露也无法还原
3. ✅ **账号加密**：使用Fernet，防止直接读取
4. ✅ **用户可控**：支持自行修改密码

## ⚠️ 注意事项

### 重要提醒

1. **不要删除 `secret.key`**：否则无法解密已保存的凭据
2. **不要共享 `secret.key`**：每台设备应有独立密钥
3. **备份配置文件**：定期备份 `config.json` 和 `secret.key`
4. **忘记密联系管理员**：无法通过技术手段恢复密码

### 已知限制

1. **单机版**：凭据与设备绑定，不支持跨设备同步
2. **单用户**：当前仅支持一个管理员账户
3. **无找回机制**：忘记密码需联系管理员重置
