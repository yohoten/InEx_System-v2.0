## 🔧 已修复问题

### 1. 裸except语句优化

**文件**: `ui/pages/settings_page_backup_old.py`

**问题描述**: 
发现2处使用裸`except:`语句，这会捕获所有异常（包括KeyboardInterrupt和SystemExit），可能导致程序无法正常退出或掩盖严重错误。

**修复详情**:

#### 修复1 (Line 1397)
```python
# 修复前
try:
    cursor.execute("SELECT DB_NAME()")
    db_name = cursor.fetchone()[0]
    self.log_text.append(f"[DEBUG] 数据库名称: {db_name}")
except:
    pass

# 修复后
try:
    cursor.execute("SELECT DB_NAME()")
    db_name = cursor.fetchone()[0]
    self.log_text.append(f"[DEBUG] 数据库名称: {db_name}")
except Exception as e:
    self.log_text.append(f"[WARN] 查询数据库名称失败: {str(e)}")
```

#### 修复2 (Line 1460)
```python
# 修复前
try:
    cursor.execute("SELECT @@VERSION")
    version = cursor.fetchone()[0]
    self.log_text.append(f"[INFO] SQL Anywhere 版本: {version}")
except:
    version = "未知"

# 修复后
try:
    cursor.execute("SELECT @@VERSION")
    version = cursor.fetchone()[0]
    self.log_text.append(f"[INFO] SQL Anywhere 版本: {version}")
except Exception as e:
    self.log_text.append(f"[WARN] 查询版本信息失败: {str(e)}")
    version = "未知"
```

**改进效果**:
- ✅ 具体异常捕获，避免捕获系统信号
- ✅ 添加详细错误日志，便于问题排查
- ✅ 符合Python最佳实践（PEP 8）
