# 月报表 - 分类消费趋势图功能说明

## 📊 功能概述

在月报表页面的图表类型中新增了**"分类消费趋势"**选项，替代原有的雷达图功能。该功能以**折线/曲线风格**展示不同消费类型在选定时间范围内的支出变化趋势。

## ✨ 主要特性

### 1. 多类别对比
- 同时显示多个消费类型的支出趋势曲线
- 每条曲线使用不同颜色区分（8色循环）
- 支持图例标识，清晰标注各曲线对应的消费类型

### 2. 灵活筛选
提供三个维度的筛选条件：

#### 账套号筛选
- 下拉选择框显示数据库中所有可用的账套号
- 自动选中当前登录的账套号作为默认值
- 支持切换不同账套查看对应数据

#### 时间范围
- 起始日期和结束日期选择器（带日历弹窗）
- 默认显示最近3个月的数据
- 支持自定义任意时间范围

#### 消费类型
- 可选择查看特定消费类型或"全部类型"
- 下拉列表显示所有已定义的支出类型
- 选择"全部类型"时显示所有类型的趋势对比

### 3. 可视化优化
- **折线图样式**：带标记点的平滑曲线，清晰展示每个时间点的数据
- **货币格式**：Y轴自动格式化为人民币格式（¥符号）
- **日期标签**：X轴日期标签旋转45度，便于阅读
- **网格辅助**：淡灰色虚线网格，辅助数据读取
- **图例位置**：右侧显示，不遮挡数据区域
- **标题信息**：显示时间范围和筛选的消费类型

## 🎯 使用方法

### 步骤1：选择图表类型
在月报表页面顶部的图表类型选择区，点击**"分类消费趋势"**单选按钮。

### 步骤2：设置筛选条件
筛选区域会自动显示，包含以下控件：

1. **账套号**：选择要查看的账套号（默认当前账套）
2. **起始日期**：设置查询的开始日期（默认3个月前）
3. **结束日期**：设置查询的结束日期（默认今天）
4. **消费类型**：选择特定类型或"全部类型"

### 步骤3：刷新图表
点击**"🔄 刷新图表"**按钮，系统会根据筛选条件重新查询数据并绘制趋势图。

> **提示**：也可以切换到其他图表类型再切回"分类消费趋势"，同样会触发刷新。

### 数据查询逻辑
```sql
SELECT s.rq, c.zc_name, s.je 
FROM sz_sheet_zc s
LEFT JOIN sz_c_zc c ON s.zc_code = c.zc_code
WHERE s.zth = ?           -- 账套号筛选
AND s.rq >= ?             -- 起始日期
AND s.rq <= ?             -- 结束日期
[AND c.zc_name = ?]       -- 消费类型筛选（可选）
ORDER BY s.rq ASC
```

### 数据处理流程
1. **查询原始数据**：从支出表和类型码表联合查询
2. **Pandas处理**：转换为DataFrame，解析日期格式
3. **分组聚合**：按日期和类别分组求和
4. **Numpy转换**：将数据转换为numpy数组（避免matplotlib警告）⭐ 优化
5. **绘制曲线**：为每个类别创建一条折线

### 性能优化（2026-05-02更新）

#### 1. Matplotlib兼容性优化
为避免matplotlib的FutureWarning警告，已将pandas DataFrame数据转换为numpy数组后再传递给绘图函数：

```python
# 优化前（会触发警告）
ax.plot(category_data['date'], category_data['amount'], ...)

# 优化后（消除警告）
import numpy as np
dates = np.array(category_data['date'])
amounts = np.array(category_data['amount'])
ax.plot(dates, amounts, ...)
```

**原因**：matplotlib新版本（3.6+）弃用了直接对pandas Series进行多维索引的方式，显式转换为numpy数组可确保兼容性。

#### 2. matplotlib legend参数兼容性（2026-05-02修复）
移除了`legend()`方法中的`title_fontsize`参数，以兼容旧版本matplotlib（<3.5）：

```
# 修复前（旧版本matplotlib不支持）
ax.legend(title="标题", ..., title_fontsize=9)

# 修复后（兼容所有版本）
ax.legend(title="标题", ..., fontsize=8)
```

#### 3. 消费类型筛选逻辑修正（2026-05-02修复）
修正了SQL查询中的筛选条件，使用`zc_code`而不是`zc_name`进行筛选：

```python
# 修复前（错误：用名称匹配代码）
sql += " AND c.zc_name = ?"
params.append(expense_type)  # expense_type是代码如"01"

# 修复后（正确：用代码匹配代码）
sql += " AND s.zc_code = ?"
params.append(expense_type)
```

**影响**：修复前选择特定消费类型时查询返回0条记录，修复后可以正常筛选。

## 🆕 数据库操作菜单功能（2026-05-02新增）

### 功能概述
在主窗口"编辑"菜单的"数据库"子菜单中，实现了三个核心数据库操作功能：

1. **🔗 连接数据库** - 通过图形化对话框配置并连接数据库
2. **❌ 断开连接** - 安全断开当前数据库连接
3. **🔍 测试连接** - 验证数据库配置是否正确

### 使用步骤

#### 1. 连接数据库
1. 点击菜单栏：**编辑** → **数据库** → **连接数据库(C)**
2. 在弹出的对话框中选择数据库类型（SQLite/MySQL/Sybase）
3. 填写相应的连接参数：
   - **SQLite**：点击"浏览"按钮选择.db文件
   - **MySQL**：输入主机、端口、用户名、密码、数据库名
4. 点击"**✅ 连接数据库**"绿色按钮
5. 等待连接完成，显示成功提示
6. 自动刷新当前页面数据

#### 2. 断开连接
1. 点击菜单栏：**编辑** → **数据库** → **断开连接(D)**
2. 确认对话框中点击"**是**"
3. 数据库连接已断开，状态栏显示提示信息

#### 3. 测试连接
1. 点击菜单栏：**编辑** → **数据库** → **测试连接(T)**
2. 填写数据库连接参数
3. 点击"**🔍 测试连接**"蓝色按钮
4. 查看测试结果和响应时间
5. 如果测试成功，可以点击"✅ 连接数据库"正式连接

### 界面截图说明

**数据库连接对话框包含三个按钮**：
- 🔍 **测试连接**（蓝色）- 仅测试不保存连接
- ✅ **连接数据库**（绿色）- 正式连接并保存状态
- 💾 **保存配置**（紫色）- 保存配置到config.json

### 支持的数据库类型

| 数据库类型 | 状态 | 所需参数 |
|-----------|------|---------|
| SQLite | ✅ 完全支持 | 数据库文件路径 |
| MySQL 8.0 | ✅ 完全支持 | 主机、端口、用户名、密码、数据库名 |
| Sybase SQL Anywhere 9 | 🚧 开发中 | DSN、用户ID、密码、数据库名 |

### 注意事项

⚠️ **重要提示**：
1. 断开连接前请确保已保存所有未提交的数据
2. 连接失败时请检查网络连接和数据库服务状态
3. MySQL连接需要安装pymysql库：`pip install pymysql`
4. 连接成功后会自动刷新当前页面数据

### 故障排查

**问题1：连接SQLite时提示"文件不存在"**
- 解决：确保选择的.db文件路径正确，文件确实存在

**问题2：连接MySQL时提示"连接超时"**
- 解决：检查MySQL服务是否启动，防火墙是否允许3306端口

**问题3：连接MySQL时提示"认证失败"**
- 解决：检查用户名和密码是否正确，注意大小写

**问题4：断开连接后无法操作数据**
- 解决：这是正常行为，需要重新连接数据库才能继续操作
