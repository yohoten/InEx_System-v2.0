项目背景与痛点

现状痛点

  • 个人及小商户收支记录零散，Excel 管理效率低、易出错
  • 缺乏直观的数据可视化工具，难以发现消费规律
  • 市面记账软件要么功能单一（仅记录），要么过于复杂（财务ERP）
  • 数据隐私与本地化存储需求被普遍忽视
  • 缺少智能化消费分析建议，用户难以优化财务结构

我们的方案

InEx_System —— 基于 PyQt5 构建的跨数据库桌面端收支管理系统，集记账、分析、AI 建议于一体，以"专业财务内核 + 智能分析外脑 + 极简操作体验"三位一体，兼顾易用性与企业级能力。

表现层 PyQt5 GUI — 主窗口框架 + QStackedWidget 页面路由 + 侧边栏导航 + 完整菜单栏体系 + QSplashScreen 启动画面 + Toast 消息组件

工具层 15+ 核心依赖 — pandas · numpy · matplotlib · seaborn · scipy · reportlab · openpyxl · cryptography · requests (DeepSeek API) · DBUtils

核心亮点：多数据库架构

基于策略模式 + 工厂模式实现 DatabaseBackend 抽象基类，一套业务代码适配三种异构数据库，SQL 方言自动适配

AI 智能消费分析引擎

消费习惯深度分析
Top 5 消费类别排名与占比 · 每月消费趋势判定（线性回归斜率 — 上升 / 下降 / 稳定）· 月均 / 最高 / 最低消费量化
异常消费自动检测
基于统计学方法（均值 + 2σ 阈值），自动筛查异常大额交易，按异常分数降序排列并展示触发原因
DeepSeek AI 集成
结构化 prompt 将分析数据发送至 DeepSeek 大模型，生成 3~5 条个性化、可执行的理财优化建议
离线规则引擎降级
无 API 或网络异常时，自动切换为统计规则引擎——超支警告 · 趋势提醒 · 预算分配建议 · 应急基金建议

双引擎架构设计：SpendingAnalyzer 类融合统计分析（scipy 线性回归趋势判断、标准差异常检测）与 LLM 提示工程。API Key 通过 cryptography 库 AES 加密存储，兼顾智能化与安全性。
