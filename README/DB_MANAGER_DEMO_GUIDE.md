### 场景 1: 折叠侧边栏获得更多编辑空间

1. 打开数据库管理对话框

### 场景 2: SQL 语法高亮效果

**测试代码：**
```sql
-- 这是一个注释示例
SELECT sr.id, sr.rq, sr.je 
FROM sz_sheet_sr sr
WHERE sr.je > 1000
  AND sr.rq LIKE '2024%'
ORDER BY sr.je DESC
LIMIT 50;
```

**高亮效果：**
- `-- 这是一个注释示例` → 🟢 绿色斜体
- `SELECT`, `FROM`, `WHERE`, `AND`, `LIKE`, `ORDER BY`, `DESC`, `LIMIT` → 🔵 蓝色加粗
- `'2024%'` → 🔴 红色
- `1000`, `50` → 🟡 橙色
- `sr.id`, `sr.rq`, `sr.je` → ⚪ 默认黑色

### 场景 5: 实时筛选数据

**操作步骤：**
1. 执行查询获取结果集
2. 在筛选框输入关键词，如："2024"
3. 表格立即过滤，只显示包含"2024"的行
4. 继续输入："2024-01"
5. 表格进一步缩小范围
6. 点击 **"清除筛选"** 按钮恢复全部数据

**筛选效果：**
```
原始数据: 1000 条记录
输入 "2024": 856 条记录
输入 "2024-01": 123 条记录
清除筛选: 1000 条记录（恢复）
```

### 场景 6: 数据分页导航

**操作步骤：**
1. 执行查询返回 1000 条记录
2. 观察表格底部显示：
   - 记录数: 1000
   - 第 1/10 页（假设每页100条）

6. 从下拉框选择 **"50"**

**分页控件布局：**
```
[◀ 上一页]  第 1/10 页  [下一页 ▶]  每页: [100 ▼]  [📤 导出为 CSV]
```

**性能对比：**
| 记录数 | 不分页渲染时间 | 分页渲染时间 | 提升 |
|--------|---------------|-------------|------|
| 100    | 0.05秒        | 0.05秒      | 无差异 |
| 1000   | 0.5秒         | 0.05秒      | 10倍  |
| 10000  | 5秒           | 0.05秒      | 100倍 |
| 50000  | 25秒+         | 0.05秒      | 500倍+|

### 场景 8: SQL 模板快速生成

**操作步骤：**
1. 点击 SQL 编辑器顶部的模板下拉框
2. 选择 **"SELECT * FROM 表名"**
3. 编辑器自动填充：
   ```sql
   SELECT * FROM table_name;
   ```
4. 将 `table_name` 替换为实际表名
5. 点击 **"▶ 执行 SQL"** 运行

**可用模板：**
- SELECT * FROM 表名
- INSERT INTO 表名 VALUES (...)
- UPDATE 表名 SET ... WHERE ...
- DELETE FROM 表名 WHERE ...
- COUNT(*) 统计记录数

### 场景 9: SQL 格式化

**操作前：**
```sql
select id,rq,je from sz_sheet_sr where je>1000 order by rq desc
```

**点击 "✨ 格式化" 按钮后：**
```sql
SELECT id,rq,je FROM sz_sheet_sr WHERE je>1000 ORDER BY rq DESC
```

关键字自动转换为大写，提升可读性。

### 场景 10: 导入/导出 SQL 文件

**导入流程：**
1. 点击 **"📂 导入 SQL 文件"**
2. 选择 `.sql` 文件
3. 系统检测文件编码（UTF-8/GBK等）
4. SQL 内容加载到编辑器
5. 弹窗询问是否立即执行
6. 选择"是"直接运行，或"否"先查看再决定

**导出流程：**
1. 在编辑器中编写或修改SQL
2. 点击 **"💾 保存 SQL"**
3. 选择保存路径和文件名
4. SQL 以 UTF-8 编码保存

## 🎯 最佳实践建议

### 1. 高效工作流程
```
1. 折叠侧边栏 → 专注编写SQL
2. 使用模板 → 快速生成基础语句
3. 语法高亮 → 实时检查语法
4. 执行查询 → 查看结果
5. 排序+筛选 → 定位关键数据
6. 导出CSV → 保存分析结果
```

### 2. 大数据集处理技巧
- **小数据集（<500条）**：使用默认100条/页
- **中等数据集（500-5000条）**：切换到200条/页
- **大数据集（>5000条）**：使用500条/页 + 筛选缩小范围

### 3. SQL 编写规范
- ✅ 使用格式化功能统一关键字大写
- ✅ 添加注释说明复杂逻辑
- ✅ 利用行号定位错误
- ✅ 保存常用SQL为文件

### 4. 性能优化建议
- 避免 `SELECT *` 查询大表，指定需要的列
- 使用 `LIMIT` 限制返回记录数
- 频繁查询的字段添加索引
- 定期清理执行日志

## 🔍 故障排查

### 问题 1: 语法高亮不生效
**原因：** PyQt5 版本过低  
**解决：** 升级到 PyQt5 >= 5.12

### 问题 2: 分页显示异常
**原因：** 数据模型未正确初始化  
**解决：** 重新执行SQL查询

### 问题 3: 筛选无响应
**原因：** 代理模型未设置  
**解决：** 确保先执行查询再使用筛选

### 问题 4: 侧边栏无法折叠
**原因：** 布局约束冲突  
**解决：** 重启应用或调整窗口大小
