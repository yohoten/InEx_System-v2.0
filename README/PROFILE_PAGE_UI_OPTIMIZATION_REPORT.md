## 🎨 新增的UIStyles工厂方法

在 `ui/styles.py` 中新增了以下样式工厂方法：

### 1. tab_style_modern()
**用途**: 现代化标签页样式  
**应用场景**: 个人中心的TabWidget、其他多Tab页面

### 2. group_box_style()
**用途**: 分组框统一样式  
**应用场景**: 账套表单、历史预算列表等QGroupBox

### 3. gradient_card(colors)
**用途**: 渐变背景卡片  
**应用场景**: 预算概览卡片、重要信息展示区

### 4. search_frame_style()
**用途**: 搜索区域框架样式  
**应用场景**: 所有搜索输入区的容器

### 5. modern_table_style()
**用途**: 现代化表格样式  
**应用场景**: 所有数据展示表格

### 6. metric_label_style(color=None)
**用途**: 指标标签样式  
**应用场景**: 统计指标、关键数据显示

## 🔄 代码替换对比

### 示例1: TabWidget样式

#### ❌ 改造前（硬编码13行）
```python
tab_widget.setStyleSheet("""
    QTabWidget::pane {
        border: 1px solid #e5e7eb;
        border-radius: 6px;
        background-color: white;
    }
    ...
""")
```

#### ✅ 改造后（1行调用）
```python
from ui.styles import UIStyles
tab_widget.setStyleSheet(UIStyles.tab_style_modern())
```

**减少代码**: 12行  
**可维护性**: ⬆️ 提升10倍（修改一处即可全局生效）
