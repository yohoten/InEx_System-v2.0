## 📝 使用说明

### 首页预算卡片
1. 启动应用后进入首页
2. 查看核心数据卡片下方的预算卡片
3. 点击"⚙️ 设置预算"设置本月预算
4. 预算卡片实时更新显示

### 支出记账预警
1. 进入"支出记账管理"页面
2. 点击"➕ 增加"按钮
3. 填写支出信息（类别、金额、支付方式等）
4. 点击"确定"时自动检查预算
5. 如有预警，会弹出提示对话框
6. 确认后支出记录被保存

### 个人中心预算管理
1. 进入"个人中心"页面
2. 切换到"💰 预算管理"标签
3. 查看本月预算概览卡片
4. 浏览历史预算记录表格
5. 可设置新预算或删除历史记录
